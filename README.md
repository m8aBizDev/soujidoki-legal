# soujidoki-legal

iOSアプリ「そうじどき（Soujidoki）」の法定ページ（GitHub Pages / Jekyll）。

- プライバシーポリシー: `/privacy/`
- 利用規約: `/terms/`
- 特定商取引法に基づく表記: `/tokushoho/`
- Privacy Policy (English): `/privacy-en/`
- 参加ページ（家族共有の招待リンクの受け口）: `/join/`（静的HTML・外部読み込みなし。招待の鍵はURLの#以降で受け取り、サーバーへは送られません）

サイト共通の値（連絡先・最終更新日）は `_config.yml` にあります。本文の原典はアプリ開発リポジトリ側の `docs/legal/` で管理しています。
